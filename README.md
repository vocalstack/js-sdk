# @vocalstack/sdk

The VocalStack speech API for Node (20 or newer) and browsers: one client,
`VocalStack`, with one group per resource, typed from the API's one OpenAPI
document (`/v1/openapi.json`, generated into `@vocalstack/contract`).

```ts
import { VocalStack } from '@vocalstack/sdk';

const vs = new VocalStack({ apiKey: process.env.VOCALSTACK_API_KEY }); // baseUrl defaults to https://api.vocalstack.com

// A stored transcription of a link (or `file:` a path, Blob or bytes).
const tx = await vs.transcriptions.create({ url: 'https://example.com/talk.mp3' });
const job = await vs.jobs.wait(tx.job!.recordingId); // done | failed | cropping
const { sentences } = await vs.recordings.transcript(job.recordingId);

const srt = await (await vs.recordings.export(job.recordingId, 'srt')).text();
```

## Install

Not on npm yet. The API serves its own builds to every account: [https://api.vocalstack.com/docs/guides/quickstart.md](https://api.vocalstack.com/docs/guides/quickstart.md) has the install command for the current build (it sends your API key to that host only).

## What is what

| Name | What it is | Group |
|---|---|---|
| realtime session | a signed token plus one socket; nothing stored | `vs.realtime` |
| broadcast | the link listeners open | `vs.broadcasts` |
| transcription | a file, link, microphone or stream, transcribed and stored (`live: true` for a microphone or stream) | `vs.transcriptions` |
| recording | one take inside a broadcast or a transcription | `vs.recordings` |
| job | a file or link recording's transcription work | `vs.jobs` |

The other groups: `vs.corrections`, `vs.shareLinks`, `vs.voices`,
`vs.search`, `vs.me`, `vs.languages`, `vs.rtmp`, `vs.events`, `vs.meta`.
Method names follow the document's `operationId`s (`broadcasts.startRecording`
is `POST /v1/broadcasts/{id}/recordings`); lists return arrays.

## Options

```ts
new VocalStack({
  baseUrl,          // default https://api.vocalstack.com
  apiKey,           // an API key (vs_key_…), for a server
  token,            // or, in a browser: an access token / browser token, or a getter (read per request)
  actingPrincipal,  // act for an organization (X-Acting-Principal)
  deviceId,         // correlation only (X-Device-Id)
  fetch,            // any fetch
  maxRetries: 2,    // 429s, and 503 unavailable on safe calls, retried after Retry-After (at most 60 s each)
  readyDeadlineMs,  // how long a realtime socket may take to report ready
});
```

Every call that creates something takes `{ idempotencyKey }` last.

## Realtime sessions

```ts
const session = await vs.realtime.connect({ spokenLanguage: 'en' });
session.sendAudio(pcmChunk); // raw PCM, f32le, 16 kHz, mono, as binary frames
for await (const event of session) {
  if (event.type === 'transcript.committed') render(event.segment);
}
session.eof(); // at end of source: final commits, then session.done

// A whole file through one socket, nothing stored:
const { text, segments } = await vs.realtime.transcribeFile('meeting.mp3', { spokenLanguage: 'en' });
```

- `transcript.draft` frames **fully replace** the live tail; never append them.
- `transcript.committed` segments are immutable, gapless by `segment.seq`,
  and carry word timings.
- A dropped connection ends the session (no resume): start a new one.

## Live recordings and listeners

```ts
const b = await vs.broadcasts.create({ name: 'Release standup' }); // b.code is the link
const grant = await vs.broadcasts.startRecording(b.id);           // 409 conflict + details.takeover
                                                                  // when another device records
const stream = await vs.recordings.publish(grant);                // the publisher socket
await vs.recordings.pause(grant.recording.id);
await vs.recordings.resume(grant.recording.id);
await vs.recordings.stop(grant.recording.id);                     // only from paused

// A listener (no account), holding a share link's code:
const link = await vs.broadcasts.createShareLink(b.id, { label: 'Audience' });
const anon = new VocalStack({ baseUrl, deviceId });
const sub = await anon.recordings.subscribe(grant.recording.id, { lang: 'es', shareCode: link.code, asOwner: false });
for await (const ev of sub) {
  if (ev.type === 'snapshot') render(ev.snapshot); // backfill, initial or after a gap
  if (ev.type === 'frame') apply(ev.frame);        // transcript.*, recording.state, ...
}
```

Browser microphone capture ships as `@vocalstack/sdk/mic`
(`streamMicrophone(session, { onStall, onRecover })`).

## Errors

`VocalStackError` carries `code` (the contract's closed enum), `message`,
`status`, `retryable`, `details` (quota numbers, code suggestions,
`{ recordingId, takeover }`), `headers` and `retryAfter`.

## Binary answers

`recordings.export`, `recordings.clip`, `recordings.voiceClip`, `jobs.preview`,
`voices.preview`, `voices.clonePreview` and `voices.sample` return the
`Response` itself: `.text()`, `.arrayBuffer()` or stream it.
`recordings.audioUrl` returns the signed media URL.

Verified against the language-agnostic conformance suite (`make conformance`)
and against a running API (`make sdk-e2e`). For agents: `SKILL.md`.
